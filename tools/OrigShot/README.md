# OrigShot: кадры оригинала для сравнения с портом (этап 6)

`OrigShot.exe` собирает оригинал (`original/`, коммит `dfbd814`) без изменений через проекты
`tools/GoldenGen/Original/*` и подклассом `WindowMvk` сам запускает одиночную игру в новом мире,
ставит взгляд, шлёт команды чата и сохраняет кадр в PNG. Рядом с exe кладётся OpenAL Soft под именем
`OpenAL64.dll` (в репозитории оригинала этой библиотеки нет).

Не входит в `MvkClaude.slnx`: `original/` не хранится в git.

## Сборка

```
dotnet build tools/OrigShot -c Release
dotnet build src/Hosts/Mvk.Desktop -c Release -o logs/portbin
```

Порт собирается в отдельную папку: `bin/Release` может быть занят открытой игрой. В Debug оба клиента
рисуют отладочную карту света в правом верхнем углу, поэтому сравнивать надо Release.

## Сравнение сцен

```
py tools/OrigShot/compare.py            все сцены
py tools/OrigShot/compare.py shore      одна сцена
```

Сцены описаны в `SCENES` (взгляд в градусах и команды чата). Для каждой: снимок оригинала, снимок порта
с тем же размером клиентской области (`--size`), сравнение в `logs/shots/<сцена>-cmp.png`
(оригинал | порт | разница x4) и в консоль: средняя разница и доля пикселей с разницей больше 24.

Чтобы кадры были сравнимы:
- мир каждый раз новый (слот удаляется), зерно 2;
- погода ясная (`/weather c`): начальная погода оригинала случайная (`new Rand()` в `Environment32`);
  облака меняются плавно, поэтому снимок через 12 секунд;
- `--calm`: кадр снимается в такт, где ветер около нуля (`(такт & 0x7F) == 32`). Ветер качает вершины
  воды, и при ветре на дальней воде видны точки (так и в оригинале, `docs/known-issues.md` п. 10);
- рабочая папка OrigShot — папка exe: оригинал читает `options.ini` и ассеты относительно неё.

## Ключи OrigShot

`--screenshot файл.png` (обязателен), `--shot-after сек`, `--slot`, `--seed`, `--cmd "/time n"` (можно несколько),
`--look yaw,pitch` (градусы, как у Mvk.Desktop), `--calm`, `--size ширина высота` (внешний размер окна).
Размер клиентской области пишется в `файл.png.size`.
