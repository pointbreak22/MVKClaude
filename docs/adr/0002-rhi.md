# ADR 0002: слой абстракции графики (RHI)

Статус: принято (2026-11-12).

## Решение
- Игровой код работает только с интерфейсами `Mvk.Rendering`: `IGraphicsDevice`, буферы, текстуры, пайплайны, списки команд.
- Бэкенды: `Mvk.Rendering.OpenGL` (первый, GL 3.3 / GLES 3.0) и `Mvk.Rendering.Vulkan` (позже).
- Одновременно работает один бэкенд. Выбор при запуске по настройке; если Vulkan недоступен — откат на OpenGL.
- Модель интерфейсов «в стиле Vulkan»: пайплайн = неизменяемый набор состояний; список команд записывается и потом отправляется.
  - GL: пайплайн — запомненное состояние, применяется одним вызовом; список команд — массив в памяти, проигрывается в GL-потоке.
  - Vulkan: `VkPipeline` и `VkCommandBuffer`.
- Списки команд можно записывать из нескольких потоков в обоих бэкендах.
- Шейдеры: на этапе 4 переносятся текущие GLSL 330 как есть. К этапу 10 — единый исходник GLSL 450 → SPIR-V (Vulkan) → SPIRV-Cross (GLSL 330 и GLSL ES 300).
- Различия API (диапазон глубины, ось Y, uniform/push-константы, синхронизация кадров) скрываются внутри бэкенда.
