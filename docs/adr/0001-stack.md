# ADR 0001: стек платформы

Статус: принято (2026-11-12).

## Решение
- .NET 10 (LTS). Переход на следующую версию — правка `global.json` и `Directory.Build.props`.
- Silk.NET для окна, ввода, OpenGL/GLES, Vulkan и OpenAL. Заменяет WinGL целиком и поддерживает Android через SDL.
- Avalonia — только для лаунчера и инструментов, не для игрового цикла.
- Внутриигровой GUI остаётся собственным (как в Vge), поэтому одинаков на ПК и телефоне.

## Почему не Avalonia для игры
Игровой цикл, захват мыши, низкая задержка ввода и полноэкранный рендер в Avalonia делаются через встроенный OpenGL-контрол, это обходной путь.

## Риски
- Android-поддержка Silk.NET менее зрелая, чем на ПК. Проверяется прототипом на этапе 0.
- Если не подойдёт, меняется только `Mvk.Platform` и хост Android (например, на нативный GLSurfaceView), остальное не затрагивается.
