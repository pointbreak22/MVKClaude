# Улучшения, найденные при переносе

Правило: при каждом переносе ищем, где код можно сделать чище архитектурно и быстрее.
Нейтральные к поведению улучшения применяются сразу; меняющие поведение помечаются `[ПОВЕДЕНИЕ]`
и вносятся отдельным коммитом только после проверки golden-тестами.

Статусы: **сделано**, **отложено** (ждёт переноса мест использования), **предложено**, **отклонено** (проверено замером).
