# Эталонные хэши генерации

Сюда кладутся хэши чанков, снятые со **старого** генератора (original/, коммит `dfbd814`):
`seed; chunkX; chunkZ; sha256(блоки + мет + биомы)`.

Новый генератор (`Mvk.Game`) обязан выдавать те же хэши. Расхождение допустимо только
как осознанное изменение с пометкой `[ПОВЕДЕНИЕ]` в `docs/progress.md`.
